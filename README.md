# 동네장터 🌿

가까운 이웃과 안전하게 사고파는 동네 중고거래 서비스입니다. 상품을 올리고, 반경으로 찾고, 채팅으로 이야기하고, 안전거래로 돈을 지키며 거래할 수 있어요.

데모용으로 만든 프로젝트라 이메일·문자·소셜 로그인·결제는 실제로 연결되지 않고 흉내만 냅니다(코드에 콘솔 출력으로 대신).

---

## 무엇을 할 수 있나요

- **회원가입·로그인** — 이메일과 비밀번호로 가입하고, 원하면 2단계 인증(앱 코드 또는 이메일 코드)까지 켤 수 있어요. 소셜 로그인 흐름도 흉내 냅니다.
- **내 동네 설정** — 사는 동네를 대략적으로만 저장해요. 정확한 위치나 집 주소는 아예 받지 않습니다.
- **상품 올리기·찾기** — 사진과 함께 물건을 올리고, 내 주변 반경·카테고리·가격·검색어로 찾아요. 판매중/예약중/판매완료로 나눠 보고, 더보기로 계속 넘겨 봅니다. 가격은 입력하는 동안 세 자리마다 쉼표가 붙고(복사하면 숫자만), 내 물건은 **잠시 숨겼다가 다시 보이게** 할 수도 있어요.
- **채팅** — 상품에서 바로 판매자와 대화해요.
  - 욕설은 자동으로 가려지고, 보내기 전에 **한 번 더 물어봐요**(그래도 보낼 수 있어요).
  - 전화번호·계좌번호처럼 보이는 부분은 **표시해서 알려줘요**. `영1영-5O14`처럼 바꿔 쓴 것도 잡아냅니다.
  - 상대가 답하기 전엔 사진을 못 보내고, 사진은 **미리보기로 확인한 뒤** 보내요.
  - **읽음 표시**와 **안 읽은 개수**가 보이고, 방을 나가면 내 목록에서만 사라져요(상대가 새로 보내면 다시 나타나요).
  - 차단·신고가 되고, 신고는 **이유를 고르는 방식**이에요(약속 불이행, 답 없음, 무리한 흥정, 욕설, 사기 의심 등).
- **안전거래** — 사는 사람이 보낸 돈을 서비스가 잠깐 맡아 뒀다가, 물건을 받았다고 확인하면 파는 사람에게 넘겨줘요. 틀어지면 돌려주고, 다투면 관리자가 정리합니다. **직거래 약속(장소·시간)** 을 잡아 두고, 거래가 끝나면 **후기(좋아요·보통·별로 + 한마디)** 를 남길 수 있어요. (데모라 실제 돈은 오가지 않아요.)
- **프로필** — 프로필 사진을 올리고 소개글을 써요. 공개 프로필에서는 그 사람이 파는 물건과 **받은 후기**를 볼 수 있고, 내 페이지에서는 **구매한 물건**도 볼 수 있어요.
- **관리자** — 신고 처리(시스템이 자동으로 잡아낸 건은 따로 표시), 이용 정지/해제, 부적절한 글 내리기, 분쟁 정리, 아무도 안 쓰는 **휴면 채팅방 정리**, 현황 대시보드.

## 무엇을 조심해서 만들었나요 (안전·개인정보)

- **위치는 동네 수준까지만** — 좌표를 일부러 거칠게(소수점 2자리) 저장하고, 사진에 박힌 위치 정보(EXIF/GPS)는 올릴 때 지웁니다. 정확한 위치가 새어 집을 특정당하는 일을 막아요.
- **개인정보는 암호화 저장** — 이메일·전화번호는 암호화해서 보관하고, 화면·응답 어디에도 그대로 내보내지 않아요. 상대에게는 닉네임만 보입니다.
- **권한은 매번 다시 확인** — 로그인해 있어도 요청할 때마다 계정 상태(정지·탈퇴)를 서버에서 다시 확인해서, 정지된 계정이 몰래 계속 쓰는 걸 막습니다.
- **거래 돈은 꼬이지 않게** — 안전거래의 각 단계는 정해진 순서로만 진행되고, 같은 거래가 두 번 정산되거나 같은 물건에 두 번 입금되는 일이 생기지 않도록 데이터베이스 수준에서 막았어요.
- **비밀번호 바꿀 땐 현재 비밀번호 확인**, 회원 탈퇴 같은 민감한 일은 한 번 더 본인 확인을 거칩니다.
- **입력값은 서버에서 다시 검사** — 화면에서 막아도 서버가 다시 확인해서, 이상한 값으로 우회하는 걸 차단합니다. 사진 경로·글자 수·금액·신고 사유까지 모두 서버가 다시 봅니다.
- **위험 신호는 관리자에게 조용히 전달** — 욕설, 연락처·계좌를 바꿔 쓴 흔적, 사기 신고 이력이 걸린 번호가 오가면 사용자 몰래 관리자에게 기록이 남아요. 나중에 같은 내용을 사용자가 신고하면 **한 건으로 합쳐서** 보여줍니다.
- **사기 이력 조회** — 상대가 알려준 계좌·전화번호를 확인해 볼 수 있어요(데모용 흉내 조회).
- **채팅 저장소만 따로** — 대화·신고는 별도 저장소(MongoDB)에, 나머지는 관계형 데이터베이스(PostgreSQL)에 나눠 담았어요.

## 데모 계정

비밀번호는 모두 `demo12345` 입니다.

| 용도 | 이메일 |
|---|---|
| 일반 사용자 | `demo@example.com` |
| 관리자 | `admin@example.com` |
| 판매자(샘플) | `sample-seller@example.com` |

관리자로 로그인하면 위쪽 메뉴에 **관리자**가 생기고, `/admin`에서 신고·분쟁·정지 등을 다룰 수 있어요.

> 이메일 인증·문자 인증·소셜 로그인 코드는 실제로 보내지 않고 서버 로그(`docker compose logs -f web`)에 찍힙니다.

## 실행 방법

자세한 내용은 [`docs/DEMO.md`](docs/DEMO.md) 참고.

```bash
# 1) 데이터베이스 띄우기
docker compose up -d db mongo

# 2) 테이블 만들기 (처음 한 번)
export DATABASE_URL="postgresql://app:app@localhost:5432/app"
pnpm exec prisma migrate deploy

# 3-a) 전체 컨테이너로 실행
docker compose up -d --build web ws
#   → http://localhost:3000

# 3-b) 또는 개발 모드로 실행 (빠른 수정 반영)
export MONGO_URL="mongodb://localhost:27017/chat"
pnpm dev

# (선택) 데모 데이터 채우기 — 상품·대화·안전거래·약속·후기·프로필 사진까지 한 번에
node scripts/seed-demo-full.mjs
# 여러 동네의 상품을 더 넣고 싶다면
node scripts/seed-demo.mjs
```
