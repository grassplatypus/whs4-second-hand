# 테스트 안내

이 프로젝트는 두 종류의 테스트로 확인합니다.

- **단위·컴포넌트 테스트 (Vitest)** — 함수·서비스·화면 컴포넌트를 하나씩 떼어서, 가짜 데이터베이스나 목(mock)으로 빠르게 검증합니다. 서버 없이 돌아가요.
- **E2E 테스트 (Playwright)** — 실제 데이터베이스(PostgreSQL + MongoDB)와 실제 화면을 띄워 놓고, 사용자가 클릭하듯 처음부터 끝까지 흐름을 검증합니다.

## 돌리는 법

```bash
# 단위·컴포넌트 (서버 불필요)
pnpm exec vitest run
#   node PATH가 없다면: node node_modules/vitest/vitest.mjs run

# E2E (DB·Mongo 띄우고, 개발 서버가 떠 있어야 함)
docker compose up -d db mongo
export DATABASE_URL="postgresql://app:app@localhost:5432/app"
pnpm exec prisma migrate deploy
pnpm dev &   # 다른 터미널에서
pnpm exec playwright test
```

## 단위·컴포넌트 테스트 (영역별로 무엇을 보는가)

- **인증 (`src/features/auth`)** — 회원가입·로그인 검증 규칙, 세션 발급·회전·재사용 감지, 비밀번호 해싱, 권한 확인(정지·탈퇴 계정 차단), 2단계 인증(앱/이메일)과 로그인 우회 방지, 민감 작업 본인 확인, 소셜 로그인 연결·해제.
- **상품 (`src/features/products`)** — 등록(위치 없으면 막기·초성 계산·좌표 스냅샷), 조회(판매자 개인정보 노출 안 함), 수정·삭제(소유자만), 상태 전이(판매중→예약중→판매완료), 반경 검색(거리 계산·검색어 주입 무해화), 상품 카드·상세·목록 화면, 이미지 처리.
- **채팅 (`src/features/chat`)** — 욕설 걸러내기(우회 표기까지), 대화·메시지·차단·신고, 참여자만 접근, 상대에게는 원문 욕설·내부 아이디가 안 가는지, 화면(목록·채팅방). 추가로: 사진 경로·글자 수·신고 사유의 서버 검증, 전화번호·계좌 탐지(`영1영-5O14` 같은 우회 표기·은행명 조합 인식, 가격·일반 대화 오탐 없음), 욕설 자동 기록과 사용자 신고 병합, 방 나가기→상대 메시지→재등장, 양쪽 나감→휴면→관리자 삭제, 안 읽은 개수·읽음 표시, 보내기 전 확인(욕설·사진).
- **안전거래 (`src/features/escrow`)** — 요청→조정→보관→정산/반환 단계 규칙, 누가 어떤 동작을 할 수 있는지, 같은 거래 이중 정산·같은 물건 이중 입금 막기, 금액 조작 방지, 화면. 추가로: 직거래 약속(참여자만·단계 제한·입력 검증), 거래 후기(정산 후에만·거래당 1회·상대는 서버가 결정).
- **관리자 (`src/features/admin`)** — 정지/해제(자기 자신·다른 관리자 금지), 신고 목록·처리, 강제 삭제, 분쟁 목록, 대시보드 집계, 모든 관리자 동작의 기록 남기기.
- **프로필 (`src/features/profile`)** — 소개글·닉네임·비밀번호 변경, 프로필 사진, 공개 프로필과 그 사람이 파는 물건, 탈퇴 가드(진행 중 거래·판매가 있으면 못 나가게).
- **공유 (`src/features/_shared`)** — 개인정보 암호화, 에러 처리(내부 정보 노출 안 함), 환경변수 검증.
- **API 라우트 (`src/app/api/**`)** — 각 엔드포인트가 로그인·권한을 제대로 막는지, 남의 아이디를 몸통에 실어 흉내 내도 무시하는지, 입력값을 검사하는지.

## E2E 테스트 (`e2e/` — 처음부터 끝까지)

| 파일 | 확인하는 흐름 |
|---|---|
| `health.spec.ts` | 서버·DB 살아 있는지 |
| `auth.spec.ts` · `twofactor.spec.ts` · `oauth.spec.ts` | 가입·로그인·세션·2단계 인증 강제·소셜 로그인 위조 방지 |
| `rbac.spec.ts` | 정지 계정이 즉시 막히는지, 관리자만 되는지 |
| `location.spec.ts` · `profile.spec.ts` | 동네 저장(거친 좌표만)·프로필·**탈퇴 가드** |
| `products.spec.ts` | 등록→목록/상세→검색(반경·카테고리)→상태 변경→남의 글 수정 막기→검색어 주입 무해화→이미지 |
| `chat.spec.ts` | 욕설 가림·상대 답장 전 사진 금지·참여자 격리·개인정보 없음 |
| `escrow.spec.ts` | 정상 거래(요청→조정→입금→정산)·반환·자기거래 막기·이중 입금 막기·분쟁 정리 |
| `admin.spec.ts` | 대시보드·정지/해제·강제 삭제·신고 처리·분쟁 조정 |
| `frontend.spec.ts` | **화면(프론트) 회귀** — 로그인하면 상단 메뉴가 바뀌는지, 가입 링크가 살아 있는지, 페이지를 열 때 콘솔 오류가 없는지, 없는 주소는 안내 화면이 뜨는지 |

`frontend.spec.ts`는 눈으로만 확인되던 화면 문제(로그인해도 메뉴가 그대로, 가입 버튼이 404 등)를 다시 생기지 않게 코드로 고정해 둔 것입니다.
