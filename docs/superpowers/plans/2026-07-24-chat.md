# 채팅(#4) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** 상품 기준 1:1 실시간 채팅(WS+Mongo), 첫메시지 멀티미디어 차단, KO 비속어/우회 마스킹, 차단·신고를 구현한다.

**Architecture:** `src/features/chat/`에 Mongo repo(추상화)·비속어필터·서비스. WS 서버(`src/server/ws`)는 실 JWT 인증+룸. REST(Next API)는 이력·시작·차단·신고. 단위테스트는 in-memory repo fake(실 Mongo 불요).

**Tech Stack:** Next.js 16, socket.io(+client), mongodb 드라이버, zod 4, Vitest + Playwright. 재사용: `verifyAccessToken`(tokens), `requireActiveUser`(RBAC), `AppError`, `withErrorHandling`, `prisma`(상품 조회), #3 이미지 파이프라인(EXIF strip).

**설계:** `docs/superpowers/specs/2026-07-24-chat-design.md`.

## Global Constraints
- **WS 인증:** 핸드셰이크 access JWT를 `verifyAccessToken`으로 검증, 미인증 연결 거부. 룸 join은 대화 참여자만(타인 도청 불가).
- **참여자 격리:** listMessages/sendMessage/join은 대화 참여자(buyer/seller)만. 타인 접근 403.
- **첫 메시지 텍스트만:** 새 대화 첫 메시지는 텍스트(이미지 금지, FIRST_MSG_TEXT_ONLY 400).
- **비속어 마스킹:** 전달·표시는 마스킹본. 원문은 신고 스냅샷(관리자용)에만. 정규화로 우회(ㅅㅂ, 시 발) 감지.
- **차단:** 차단 유저는 대화 시작·전송 불가(BLOCKED 403).
- **PII 없음:** 대화 목록·메시지에 이메일/전화/정확좌표 없음(상대=닉네임만). 채팅 이미지도 EXIF strip.
- REST 라우트는 `requireActiveUser`(GUEST 401/SUSPENDED 403). 저장소 이원화: 채팅=Mongo, 나머지=Postgres. 클라 에러 코드→카탈로그. UI 한/영 평어체.
- TypeScript strict. 짧은 한글 커밋, Co-Authored-By 금지. 브랜치 `feat/chat`. Node PATH 없을 때 `/c/Program Files/nodejs`.

**Interfaces:** `normalize(text)`, `maskProfanity(text): { masked, hit }`, `PROFANITY: string[]`.

### Task 3 🔴: 채팅 서비스

**Files:** Create `src/features/chat/service.ts` + test.

**Interfaces:** `startConversation(repo, prisma, buyerId, productId, firstText)`, `sendMessage(repo, senderId, conversationId, {kind, text?, imagePath?})`, `listConversations(repo, userId)`, `listMessages(repo, userId, conversationId, cursor?)`, `blockUser`/`unblockUser`, `reportMessage`/`reportUser`.

- [ ] **Step 1: 테스트(RED)** — InMemoryChatRepo + 목 prisma(product 조회):
  - startConversation: 상품 로드(없으면 404), 판매자==buyer→`SELF_CHAT` 400, 차단관계→`BLOCKED` 403, 첫 텍스트 비어있음→400, 기존 대화 재사용, 첫 메시지 저장(마스킹 적용·masked 플래그). 반환 {conversationId, message}.

- [ ] **Step 2: 구현** — 서비스는 repo + prisma(상품·닉네임). 마스킹은 filter. 첫 이미지 차단은 countMessages==0 && kind==image. report 스냅샷은 원문(관리자 판단), 일반 전달/조회는 masked.
