# 관리자(#6) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** 관리자 도구 — 제재(정지/해제)·신고 관리·강제 삭제·에스크로 분쟁 목록/조정·대시보드. 전부 requireAdmin + 감사 로그.

**Architecture:** `src/features/admin/`에 서비스(`service.ts`)·DB 표면(`db.ts`). 신고는 Mongo(ChatRepo 확장), 유저/상품/에스크로/감사는 Postgres. 얇은 라우트. 관리자 전용 UI. 마이그레이션 없음(기존 모델 재사용).

**Tech Stack:** Next.js 16, Prisma 7, mongodb, zod 4, Vitest + Playwright. 재사용: `requireAdmin`(RBAC DB-fresh), `AppError`, `withErrorHandling`, `prisma`, ChatRepo(신고), #5 `resolveDispute`/`/api/escrow/[id]/resolve`(분쟁 조정), `AuthAuditLog`(감사).

**설계:** `docs/superpowers/specs/2026-07-24-admin-design.md`.

## Global Constraints
- **인가:** 전 관리자 라우트·페이지 `requireAdmin`(비관리자 403/게스트 401, 페이지는 리다이렉트). DB-fresh role.
- **권한 남용 방지:** 자기 정지 금지(`CANNOT_SANCTION_SELF` 400), 다른 ADMIN 정지 금지(`CANNOT_SANCTION_ADMIN` 403). 대상 USER/SUSPENDED만.
- **감사:** 모든 관리자 액션 `AuthAuditLog` 기록(ADMIN_SUSPEND/LIFT/FORCE_DELETE/RESOLVE_REPORT/DISMISS_REPORT).
- **신고 원문:** snapshot(원문)은 관리자 화면에만(#4 rawText 관리자 전용과 정합).
- **PII 최소:** 이메일/전화 복호화 안 함(닉네임·id·수치만). 강제삭제는 soft.
- 관리자 id는 인증에서만(바디 위조 무시). 클라 에러 코드→카탈로그. UI 한/영 평어체.
- TypeScript strict. 짧은 한글 커밋, Co-Authored-By 금지. 브랜치 `feat/admin`. Node PATH 없을 때 `/c/Program Files/nodejs`.
